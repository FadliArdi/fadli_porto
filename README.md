# Portfolio — Fadli Ardiansyah Harahap

Personal portfolio (Data Analyst / Data Scientist / ML Engineer).

## Stack
- React 19 + Vite 7
- Tailwind CSS v4
- GSAP + Framer Motion + Lenis
- React Router

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Structure
- `src/data/projectsData.js` — project content
- `src/components/` — page sections & project pages
- `public/images/`, `public/docs/` — assets
